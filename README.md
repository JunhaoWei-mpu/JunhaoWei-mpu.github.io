# Junhao Wei — Personal Academic Homepage

This is a static GitHub Pages website styled after the academic homepage layout referenced by Junhao Wei.

## Deploy

Repository name:

`JunhaoWei-mpu.github.io`

Upload the contents of this folder to the repository root, then enable GitHub Pages from `Settings → Pages → Deploy from a branch → main → / (root)`.
