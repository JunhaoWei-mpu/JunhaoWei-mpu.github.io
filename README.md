# Junhao Wei — GitHub Pages personal homepage

A responsive academic-style personal website based on the supplied CV and portrait.

## 1. Create the GitHub repository

Create a **public** repository named:

```text
YOUR_GITHUB_USERNAME.github.io
```

GitHub Pages user sites are served from that repository's `main` branch. See GitHub's official Pages quickstart for the current UI flow:
https://docs.github.com/en/pages/quickstart

## 2. Upload the files

Upload the contents of this folder, keeping the following structure:

```text
.
├── index.html
└── assets/
    ├── junhao-wei.jpg
    └── JunhaoWei-CV.pdf
```

## 3. Publish

In the repository, open **Settings → Pages** and choose **Deploy from a branch**, then select `main` and `/ (root)`.

Your site will then be available at:

```text
https://YOUR_GITHUB_USERNAME.github.io/
```

## 4. Easy future updates

The main content lives in `index.html`. The two newest papers are in the **Selected publications** section near the middle of the page.

The portrait is `assets/junhao-wei.jpg` and the downloadable CV is `assets/JunhaoWei-CV.pdf`.
